# 🚀 Resume Builder

A simple and customizable **Resume Builder** built using **HTML, CSS, and TypeScript**. This tool allows users to create, edit, and download professional resumes with ease.

## 🌟 Features

✅ **User-Friendly Interface** – Easily add and edit personal details, experience, skills, and education.  
✅ **Dynamic Resume Preview** – See real-time updates as you build your resume.  
✅ **Download as PDF/ Print** – Export your resume in a professional format.  
✅ **TailwindCSS Styling** – Modify fonts, colors, and layouts for a personalized touch.  
✅ **TypeScript-Powered** – Ensures type safety and better performance.  

## 🛠️ Technologies Used

- **HTML** – Structure of the application  
- **TailwindCSS** – Styling and responsiveness  
- **TypeScript** – Adding type safety and logic
